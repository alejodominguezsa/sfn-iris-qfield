# SFN Iris para QField

Plugin de toda la app que aplica la paleta y el logo de SFN Iris en QField (3.0 o superior).

## Instalación

En QField: **Settings → Manage plugins → Install plugin from URL** y pegar:

```
https://github.com/alejodominguezsa/sfn-iris-qfield/releases/latest/download/sfn-iris.zip
```

Después activar **SFN Iris** en la lista de plugins.
